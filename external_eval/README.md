# Baselines and experimental code

Current CoNC, exact arithmetic, matched fusion controls, strict-split protocols and frozen-prediction replay are described in the root README. The main implementation is in `conc_exact_topo_20261114/model.py`; `conc_strict_20261114/` records the strict experiment, baseline adapters, static analyzers and hybrid policy. `tifs/` implements the backbone and mechanism interventions. Baseline implementations are under `baselines/` and the historical model code is under `../transformer_gru_v76_v2/`.

`requirements-baselines.txt`, `requirements-deepwukong.txt`, and `requirements-deepdfa.txt` describe separate dependencies. Full native-tool reruns require the documented Cppcheck, Clang, Frama-C Eva and Joern environments. Original campaign orchestration also refers to research-stage intermediate files that are not all included in the compact release. The portable replay and strict fusion entry points are described in the root README; reference predictions and per-seed results are in `../data/current/` and `../results/current/`.
